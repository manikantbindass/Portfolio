## 🌌 Overview

A **responsive engineering portfolio** built with Next.js 16, React, TypeScript, Tailwind CSS, and Framer Motion — showcasing work across **AI/ML, backend systems, full stack development, blockchain, and system design**.

The original cosmic identity lives on: **rolling technology marquees, a scroll-driven moon, starfield and aurora lighting, typewriter roles, interactive cursor, floating navigation, and animated counters**. Refined glass surfaces support both dark and light themes.

> 🔗 **Live:** [Explore the portfolio](https://portfolio-ten-omega-4ibkho6f7u.vercel.app) · **16 project case studies** · **6 recent highlights** · **3 professional resumes**

## 🛠️ Getting Started

### Prerequisites

- **Node.js 24 LTS** and npm
- Git

### Installation

```bash
git clone https://github.com/manikantbindass/Portfolio.git
cd Portfolio
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Validation & Production Build

```bash
npm run typecheck
npm run lint
npm test
npm run build
npm start
```

With a server running, validate the routes, PDF files, screenshot assets, metadata, API source labels, and unknown-route responses:

```bash
node scripts/smoke.mjs
```

Set `PORTFOLIO_TEST_URL` for another host or port. No new environment variables or API tokens are required for the portfolio's public statistics integrations.
