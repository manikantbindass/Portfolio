These are unchanged local application captures with explicitly fictional sample knowledge. They are not generated mockups. Gallery captions preserve that distinction and link to each original at the pinned commit.

The [live Lumina product tour](https://enterprise-rag-knowledge-assistant-three.vercel.app) is a public visual showcase. The authenticated ingestion, retrieval, and chat runtime is started locally as documented in the project README. OpenAI/Ollama generation requires server configuration; SQLite and lexical BM25 describe the supported runtime, while PostgreSQL/pgvector and enterprise SSO remain roadmap items.

The Portfolio README header and footer are repository-native SVGs (`portfolio-header.svg` and `portfolio-footer.svg`). They contain self-contained CSS animations, static fallback artwork, accessible titles/descriptions, and reduced-motion styles; no scripts, remote fonts, or external animation services are used.
