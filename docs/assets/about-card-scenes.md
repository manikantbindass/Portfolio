# About card scenes

Generated using the built-in imagegen tool and encoded as WebP at the original resolution for faster page loading. These are photorealistic generated animation sequences, rather than recorded video.

Each asset has four columns and two rows of square frames. The UI loops eight frames in four seconds and crossfades adjacent frames to soften transitions. All card motion shares the About play/pause control, with static reduced-motion and opaque reduced-transparency fallbacks.
