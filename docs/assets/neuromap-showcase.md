[Release v0.1.1](https://github.com/manikantbindass/NeuroMap.AI/releases/tag/v0.1.1) was inspected for the genuine Windows x64 EXE, signed Android APK, user manual, and checksum artifacts. The portfolio links directly to the published assets; it does not redistribute the installers. Both clients require a functioning server. The Windows publisher is unsigned, Android device runtime verification remains pending, and no iOS IPA is available.

The user confirmed there is no hosted deployment; `live` remains `null`. No public demo account or medical inference is claimed. The supported classifier uses synthetic tabular features, while NIfTI geometry/intensity inspection is separate. Project-reported verification is identified as such rather than represented as tests executed in this portfolio task.

`NeuroMapGlassHero` is original code-native decorative artwork: paired glass lobes, mathematically positioned points, travelling connection signals, and a moving scan plane. It is not a clinical anatomical model, reconstruction, or application result. It inherits the portfolio glass frame and has pause, reduced-motion, mobile, and reduced-transparency support. Portfolio README header/footer artwork uses matching neural connections with static fallbacks.
